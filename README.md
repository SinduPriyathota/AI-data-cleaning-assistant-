🧹 AI Data Cleaning Assistant

📌 About the Project

The AI Data Cleaning Assistant is a Python-based web application designed to simplify the data cleaning process. It helps users identify missing values, remove duplicate records, clean datasets, and visualize data.

🎯 Objectives

- Simplify data cleaning and preprocessing.
- Identify missing values in datasets.
- Remove duplicate records.
- Improve data quality.
- Visualize data for better understanding.

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn

✨ Key Features

- Upload CSV datasets.
- Preview datasets.
- Detect missing values.
- Remove duplicate records.
- Clean and process data.
- Generate data visualizations.
- Download cleaned datasets.

⚙️ How to Run the Project

Step 1: Install the required libraries

python -m pip install streamlit pandas numpy matplotlib seaborn

Step 2: Run the application

python -m streamlit run app.py

Step 3: Use the application

Open the local URL displayed in your terminal, upload a CSV file, and use the available data cleaning and visualization features.
